Privacy Policy

Save Notification — Windows Notification Storage App
Last updated: November 7, 2026

1. Overview

Save Notification ("the App") is a Windows desktop application that saves, manages, and searches Windows notifications locally on your device. We are committed to protecting your privacy. This Privacy Policy explains what data the App collects, how it is used, and your rights regarding that data.

2. Data Collection

The App does NOT collect, transmit, or store any personal data on external servers.

All data is stored exclusively on your local device in a SQLite database located at:

%LOCALAPPDATA%\SaveNotification\notifications.db

The types of data stored locally include:

  • Notification content — title, message text, and timestamp of Windows toast notifications from apps you choose to monitor
  • App identifiers — names of applications that send notifications (e.g., "Microsoft Edge", "Telegram")
  • User preferences — language setting, starred notifications, monitored app list, and Telegram configuration (if enabled by user)

3. Data Storage & Security

  • All data is stored locally on your device only
  • No data is sent to our servers or any third-party servers
  • No cloud sync, no analytics, no tracking
  • The database file is protected by your Windows user account permissions
  • You can delete all data at any time by using the "Clean up" feature in the App or by deleting the database file directly

4. Telegram Integration (Optional)

The App offers an optional feature to forward notifications to a Telegram bot. This feature is:

  • Disabled by default — you must explicitly enable it and provide your own Bot Token and Chat ID
  • Direct communication — when enabled, notification data is sent directly from your device to the Telegram Bot API (api.telegram.org). No data passes through our servers
  • User-controlled — you can disable this feature at any time in Settings, and no further data will be sent
  • Your credentials — Bot Token and Chat ID are stored locally on your device and are never shared with us

5. Windows Notification Access

The App uses the Windows UserNotificationListener API to read toast notifications. This requires your explicit permission through Windows Settings. The App:

  • Only reads notifications from apps you choose to monitor
  • Does not modify or interact with notifications in any way
  • Does not read notification content from apps you have not enabled for monitoring
  • You can revoke notification access at any time via Windows Settings → System → Notifications

6. Third-Party Services

The App does not integrate with any third-party analytics, advertising, or tracking services. The only external service the App may communicate with is:

  • Telegram Bot API (api.telegram.org) — only when you explicitly enable and configure the Telegram forwarding feature
  • Microsoft Store — for license verification and in-app purchases (handled by the Windows operating system, not by the App)

7. Children's Privacy

The App does not knowingly collect any personal information from children under the age of 13. The App stores only notification data generated by other applications on the user's device.

8. Your Rights

You have full control over your data:

  • View — all saved notifications are visible in the App
  • Delete — delete individual notifications, or use "Clean up" to remove old data
  • Export — export your data to CSV format (Pro feature)
  • Complete removal — uninstalling the App removes all local data

9. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected in the "Last updated" date at the top of this page. Continued use of the App after changes constitutes acceptance of the updated policy.
